\# Amazon India Sales \& Operations Dashboard



\## Project Overview



An Excel-based sales and operations dashboard designed to analyze business performance across sales, profitability, product categories, order status, payment methods, fulfillment methods, and geographic regions.



\## Objectives



\* Analyze overall sales and profit performance.

\* Identify the best-performing product categories.

\* Analyze the top 10 products by sales.

\* Monitor order statuses, returns, and cancellations.

\* Compare sales and profit across payment methods.

\* Analyze fulfillment performance.

\* Compare sales, profit, and order records across states.



\## Tools Used



\* Microsoft Excel

\* PivotTables and summary tables

\* Excel Charts

\* Data Analysis and Visualization



\## Key Performance Indicators



\* Total Sales

\* Total Profit

\* Total Orders

\* Units Sold

\* Average Order Value

\* Profit Margin

\* Return Rate

\* Cancellation Rate



\## Dashboard Sections



1\. Overall Sales \& Profit Performance

2\. Category \& Product Performance

3\. Order Status \& Revenue Loss

4\. Payment, Fulfillment \& Geographic Performance



\## Workbook Structure



\* Dashboard: KPI cards and visualizations.

\* Analysis: Supporting summary tables.

\* Source Data: Dataset used for analysis.

\* README: Project documentation.



\## How to Use



1\. Download the Excel workbook.

2\. Open it in Microsoft Excel.

3\. Select the Dashboard worksheet.

4\. Explore the charts and KPI cards.

5\. Review the Analysis worksheet for supporting figures.



\## Important Note



This project was created for data analysis and visualization practice. KPI calculations and business definitions should be validated against the source dataset before making business decisions.
